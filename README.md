# Pfdhfr Molecular Analysis

## Project Overview

This repository contains Python scripts developed for the molecular analysis of Plasmodium falciparum Pfdhfr sequences from five clinical isolates collected in Ifo LGA, Ogun State, Nigeria.

The project investigates resistance-associated genetic variations in the Pfdhfr gene and compares local sequences with published sequences from different geographical regions.

## Research Findings

The five Ifo isolates carried the following Pfdhfr substitutions:

- A152T (N51I)
- T175C (C59R)
- G323A (S108N)

All five isolates showed the triple-mutant genotype.

## Scripts

### make_pfdhfr_chromatograms_fixed.py

Generates annotated Sanger chromatogram figures highlighting the principal nucleotide substitutions.
